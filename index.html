01

Что такое экономика обмена?

🥪

У тебя есть бутерброд, а у друга — яблоко. Ты хочешь яблоко, он хочет бутерброд. Вы меняетесь — и оба довольны. Это и есть обмен. Экономика обмена — модель, в которой люди не производят товары, а торгуют тем, что уже имеют.

[ ФОРМАЛЬНАЯ МОДЕЛЬ ]

Два блага, два потребителя A и B. Каждый потребитель $k$ владеет начальным запасом:

$$\omega^k = (\omega_1^k,\ \omega_2^k) \geq 0$$

и имеет функцию полезности $u^k(x_1^k, x_2^k)$. Совокупный запас блага $i$:

$$\bar{\omega}_i = \omega_i^A + \omega_i^B > 0$$

02

Ящик Эджворта

📄

Возьми прямоугольный лист бумаги. Ширина — весь запас блага 1, высота — весь запас блага 2. Любая точка внутри — какое-то распределение между двумя людьми. Это и есть ящик Эджворта.

[ ДОПУСТИМОЕ РАСПРЕДЕЛЕНИЕ ]

Распределение $x = (x_1^A, x_2^A, x_1^B, x_2^B)$ допустимо, если:

$$x_i^A + x_i^B = \bar{\omega}_i \quad \text{для } i = 1, 2$$

Ничего не создаётся и не исчезает — блага только перераспределяются.

03

Парето-оптимальные распределения

⚖️

Если можно перераспределить блага так, чтобы кому-то стало лучше, а никому — не хуже, то текущее распределение неэффективно. Если такого перераспределения нет — оно Парето-оптимально.

[ ОПРЕДЕЛЕНИЕ ]

Распределение $\bar{x}$ Парето-оптимально (ПО), если не существует допустимого $\hat{x}$ такого, что:

$$u^A(\hat{x}^A) \geq u^A(\bar{x}^A) \quad \text{и} \quad u^B(\hat{x}^B) \geq u^B(\bar{x}^B)$$

причём хотя бы одно неравенство строгое. Нельзя улучшить положение одного, не ухудшив другого.

[ ПАРЕТО-УЛУЧШЕНИЕ ]

Переход, при котором никому не стало хуже, а кому-то стало лучше. В Парето-оптимальном распределении Парето-улучшений не существует.

04

Как найти Парето-оптимум? MRS

Предельная норма замещения $MRS_{12}^k$ — количество блага 2, от которого потребитель готов отказаться ради единицы блага 1, оставаясь на той же кривой безразличия:

$$MRS_{12}^k = \frac{\partial u^k / \partial x_1^k}{\partial u^k / \partial x_2^k}$$
[ УТВЕРЖДЕНИЕ 1 — необходимое условие внутреннего ПО ]

Если предпочтения строго монотонны и дифференцируемы, то во внутреннем ПО:

$$MRS_{12}^A(\bar{x}^A) = MRS_{12}^B(\bar{x}^B)$$

Геометрически: кривые безразличия потребителей касаются друг друга.

[ ⚠ ЗАМЕЧАНИЕ ]

Это условие — необходимое для внутреннего ПО, но не для граничного. В граничных ПО равенство MRS может не выполняться.

[ УТВЕРЖДЕНИЕ 2 — необходимое и достаточное условие ]

Если предпочтения строго монотонны, выпуклы и дифференцируемы, то $MRS_{12}^A = MRS_{12}^B$ — необходимое и достаточное условие внутреннего ПО.

05

Пример: функции Кобба-Дугласа

[ ПОСТАНОВКА ]
$$u^A = (x_1^A)^\alpha (x_2^A)^{1-\alpha}, \quad u^B = (x_1^B)^\beta (x_2^B)^{1-\beta}$$

MRS для Кобба-Дугласа:

$$MRS_{12}^A = \frac{\alpha\, x_2^A}{(1-\alpha)\, x_1^A}, \quad MRS_{12}^B = \frac{\beta\, x_2^B}{(1-\beta)\, x_1^B}$$

Из условия $MRS^A = MRS^B$ и условий допустимости выводится контрактная кривая — множество внутренних ПО:

$$x_2^A(x_1^A) = \frac{\beta(1-\alpha)\,\bar\omega_2\, x_1^A}{\alpha\bar\omega_1(1-\beta) + x_1^A(\beta - \alpha)}, \quad x_1^A \in (0,\, \bar\omega_1)$$
СоотношениеФорма контрактной кривой
$\alpha = \beta$Прямая (диагональ ящика)
$\beta > \alpha$Выпуклая (выше диагонали)
$\beta < \alpha$Вогнутая (ниже диагонали)
💡 Меняй параметры α и β в интерактивном ящике выше, чтобы наблюдать, как форма контрактной кривой зависит от соотношения предпочтений.
06

Равновесие по Вальрасу

🏪

На рынке каждый приходит со своим товаром, видит цены и решает — купить или продать. Если при каких-то ценах спрос на каждый товар равен предложению — это равновесие.

[ ОПРЕДЕЛЕНИЕ ]

Равновесие по Вальрасу — набор $(\tilde{p}, \tilde{x}^A, \tilde{x}^B)$, такой что:

(1) Каждый потребитель $k$ решает: $\max u^k(x^k)$ при $p_1 x_1^k + p_2 x_2^k \leq p_1\omega_1^k + p_2\omega_2^k$.

(2) Рынки сбалансированы:

$$\tilde{x}_i^A + \tilde{x}_i^B = \bar\omega_i \quad \text{для } i = 1, 2$$
[ ХАРАКТЕРИСТИКА ВНУТРЕННЕГО РАВНОВЕСИЯ ]
$$MRS_{12}^A(\tilde{x}^A) = MRS_{12}^B(\tilde{x}^B) = \frac{\tilde{p}_1}{\tilde{p}_2}$$

Кривые безразличия обоих потребителей касаются бюджетной линии в одной точке.

[ НЕЙТРАЛЬНОСТЬ МАСШТАБА ЦЕН ]

Если $(p_1, p_2)$ — равновесный вектор, то $(\lambda p_1, \lambda p_2)$ тоже равновесный при любом $\lambda > 0$. Поэтому нормируют, например, $p_2 = 1$.

07

Закон Вальраса

[ ИЗБЫТОЧНЫЙ СПРОС ]
$$z_i(p) = x_i^A(p) + x_i^B(p) - \omega_i^A - \omega_i^B$$
$z_i > 0$Дефицит — спрос превышает запас
$z_i < 0$Профицит — запас превышает спрос
$z_i = 0$Равновесие — рынок сбалансирован
[ ЗАКОН ВАЛЬРАСА ]

При монотонных предпочтениях и при любых ценах $(p_1, p_2)$:

$$p_1\, z_1(p) + p_2\, z_2(p) = 0$$

Совокупная стоимость избыточного спроса всегда равна нулю.

1 Дефицит и профицит не могут возникнуть одновременно. Если на одном рынке профицит — на другом обязательно дефицит.
2 Если рынок блага 1 уравновешен ($z_1 = 0$), то автоматически $z_2 = 0$. Достаточно уравновесить $N-1$ рынок из $N$.
08

Теоремы благосостояния

I
Первая теорема благосостояния
Если предпочтения монотонны, то любое равновесное по Вальрасу распределение является Парето-оптимальным.
Смысл: Децентрализованный рынок автоматически приводит к эффективному распределению — без центрального планирования.
II
Вторая теорема благосостояния
При выпуклости предпочтений любое ПО распределение достижимо как равновесие по Вальрасу при подходящем перераспределении начальных запасов.
Смысл: Чтобы достичь нужного эффективного распределения — достаточно правильно перераспределить запасы, а рынок сам придёт к результату.
