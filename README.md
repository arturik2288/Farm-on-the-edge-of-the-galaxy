# Farm-on-the-edge-of-the-galaxy

Короткая учебная игра для освоения базовых принципов микроэкономики: производство, потребление и торговля.

## Актуальность

* Игра с экономической логикой помогает наглядно усваивать ключевые идеи микроэкономики.
* Проект совмещает прикладную экономику и современную веб-разработку.
* Браузерный формат обеспечивает доступность: не требует установки и работает на обычных устройствах.

## Описание

Вы играете за персонажа на другой планете. Он производит два блага и потребляет два блага. Чтобы получить нужные ресурсы, он обменивает (продаёт) произведённые блага — здесь и проявляется микроэкономический аспект торговли.
